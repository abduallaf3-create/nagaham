# Nagham (نغم)

A music player: your own music, songs from around the world, YouTube Music and Spotify, with themes.

## Windows
Get **NaghamSetup.exe** from the [latest release](../../releases/latest) and run it.
Nagham checks GitHub by itself and offers new versions inside the app.

## Source
- `nagham/` – the app (Go, no outside packages; the interface is in `nagham/web`)
- `nagham-setup/` – the Windows installer

No API keys or secrets are stored in this repository — each user enters their own in the app.
